# Отчёт по лабораторной работе «OpenPLC: управление резервуаром»

## Требования к сдаче

Сдайте архив `Группа_Фамилия_OpenPLC.zip`, содержащий:

- отчёт DOCX или PDF, заполненный по этому шаблону;
- папку собственного проекта OpenPLC с POU, устройством, Modbus-сервером и задачей (не только скриншоты);
- `TankControl-modified.txt`: таблицу добавленных переменных и полное изменённое тело ST;
- использованный `docker-compose.yml` для воспроизведения настройки;
- при необходимости оригиналы скриншотов, если в отчёте не видны значения.

Не включайте установщики EXE, образы Docker, том Runtime, пароли и сгенерированный каталог build. Не сдавайте проект с временными присваиваниями тестовых входов. Оригинал рабочего проекта у себя сохраните.

Используйте [готовый DOCX](REPORT-TEMPLATE.docx) или перенесите разделы ниже в свой документ. Рекомендуемый объём — 6–12 страниц без полного листинга, но важнее полнота доказательств. Текст — 12 пт, код — моноширинный 10–11 пт; изображения должны быть читаемыми. Нумеруйте рисунки, указывайте условия опыта. Каждый тест должен содержать фактический результат; непроведённый тест обозначайте явно, а не отмечайте успешным по ожиданию.

Контрольных вопросов нет. В разделах анализа объясните, как устроен ваш работающий стенд и почему алгоритм соответствует заданию. Пустые поля в квадратных скобках замените своими данными.
