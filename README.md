# Лабораторная работа: OpenPLC и виртуальный резервуар

Требуются Windows 10/11, Docker Desktop с WSL 2 и OpenPLC Editor 4.3.2. Скачайте установщик **Windows x64 EXE** со страницы [официального релиза OpenPLC Editor v4.3.2](https://github.com/Autonomy-Logic/openplc-editor/releases/tag/v4.3.2). Python работает внутри контейнера; устанавливать его в Windows не нужно.

В Compose закреплён Runtime `v4.3.1` для Editor `4.3.2`. Не заменяйте тег на `latest`.

## Устройство стенда

OpenPLC Runtime v4 исполняет программу ST. Контейнер HMI запускает Flask и PyModbus, рассчитывает уровень воды и передаёт датчики в PLC. Браузер показывает состояние и отправляет команды. Насос включается ниже 25%, выключается при 90%; между порогами сохраняет своё состояние. Таймер непрерывной работы — 30 секунд.

| Сигнал | Location | Modbus coil (нумерация с нуля) |
|---|---|---|
| StartBtn | `%MX0.0` | 16 |
| StopBtn | `%MX0.1` | 17 |
| ResetBtn | `%MX0.2` | 18 |
| LowLevel | `%MX0.3` | 19 |
| HighLevel | `%MX0.4` | 20 |
| Pump | `%QX1.0` | 8 |
| Alarm | `%QX1.1` | 9 |
| AutoMode | `%QX1.2` | 10 |

Смещение MX равно 16 только при настройках сервера **QX = 16 бит, MX = 8 бит**. Размеры нужно задать точно. MX здесь — команды и моделируемые датчики, а не аппаратные входы.

## Краткий запуск после настройки

Из PowerShell в каталоге с `docker-compose.yml`:

```powershell
docker compose up -d --build
docker compose ps
```

В редакторе: Runtime v4, адрес `127.0.0.1`, циклическая задача `T#20ms`, экземпляр `TankControl`; Modbus TCP включён на `0.0.0.0:502`, QX = 16, MX = 8. Соберите и загрузите программу, затем запустите её кнопкой Play. Откройте <http://localhost:8080>, дождитесь `PLC ONLINE` и нажмите START.

Порт 8443 используется редактором, 8080 — браузером. Оба опубликованы только на локальном компьютере. Modbus 502 не опубликован в Windows: HMI обращается к `openplc:502` внутри сети Docker. Modbus-сервер должен быть явно добавлен в проект PLC.

Кнопки HMI удерживают сигнал около секунды. Начальный уровень HMI — 10%; перезапуск контейнера HMI возвращает его к этому значению. `PLC ONLINE` подтверждает обмен Modbus, но сам по себе не подтверждает исполнение программы — проверяйте состояние Run в редакторе.

Завершение сеанса: STOP в HMI, затем `docker compose stop`. Данные Runtime хранятся в именованном томе `openplc-data` (Compose обычно добавляет префикс проекта). Не удаляйте этот том и не используйте `docker compose down -v`, если данные нужны.
